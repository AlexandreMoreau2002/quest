# Recettes manuelles

Une story livrée ne peut passer en revue qu’avec une recette manuelle dédiée.

Copier `story-template.md` en `story-<id>-<slug>.md`, remplir les prérequis, les étapes Given/When/Then et les résultats attendus. La recette reste à `À valider` jusqu’au retour explicite du propriétaire.
