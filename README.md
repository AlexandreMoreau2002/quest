# Quest

SaaS de progression personnelle — transforme les objectifs de vie en quêtes interactives.

## Structure

- `web/` — frontend Next.js (submodule, [quest-web](https://github.com/AlexandreMoreau2002/quest-web))
- `api/` — backend NestJS (submodule, [quest-api](https://github.com/AlexandreMoreau2002/quest-api))
- `docs/` — specs et documentation de conception
