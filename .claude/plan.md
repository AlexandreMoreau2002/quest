# Quest Delivery Plan

## Sprint actif : CRUD persistant et carte

Objectif : pouvoir créer, modifier, supprimer et visualiser des objectifs persistants sur la carte interactive.

Ordre de livraison :

1. Story 1.1 — PostgreSQL, Prisma et seed de l’objectif `Gagner beaucoup d’argent`.
2. Story 1.2 — API NestJS CRUD pour Quests et Steps.
3. Story 1.3 — Carte Next.js consommant les données API.
4. Story 1.4 — Création, édition et suppression depuis l’interface.

Chaque story doit avoir une PR vers `develop`, une documentation technique dans le service concerné et une recette dans `docs/manual-tests/` avant handoff humain.
